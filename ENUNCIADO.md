# Enunciado — Notificaciones Live Update

Construir una demostración Android de una **notificación continua y promovida** para representar una actividad iniciada por el usuario y sensible al tiempo.

La práctica simula un trayecto/entrega que avanza desde 0 hasta 100 %, muestra progreso, segmentos e hitos, solicita el tratamiento de notificación promovida cuando la plataforma lo admite y ofrece una alternativa de notificación estándar en versiones que no soportan el modelo completo.

El usuario debe poder cancelar la actividad y, al completarse, la notificación continua debe finalizar limpiamente y convertirse en una notificación normal de finalización.

No existe una base de datos asociada.
